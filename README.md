# AcousticLab 3D · 家用房间声学仿真与材料布置实验室

专为音频工程学习、家庭听音室/录音间声学规划以及**车载音响调音（小空间声学）底层原理对照**打造的交互式 3D 房间声学仿真软件。

## 核心功能

1. **矩形房间参数化 3D 建模**
   - 自由调节房间长、宽、高，实时计算容积与**施罗德频率（Schroeder Frequency）**。
   - 支持切换墙面、地面、天花板基底材质（毛坯水泥、石膏板、实木、落地玻璃窗、地毯、矿棉吊顶）。
   - 智能单向透视墙：阻挡视线的墙面自动淡化为半透明玻璃丝网，内部布局一目了然。

2. **5 类代表性声学材料拖拽摆放**
   - **三棱柱角落低频陷阱**：吸附四面竖直墙角，基于简正驻波余弦声压分布计算**位置效率权重**（墙角效率显著高于墙心）。
   - **10cm 宽频玻纤吸音板**：均衡吸收中低频至高频，拦截墙面与天花板第一反射点。
   - **3cm 薄鸡蛋棉/聚酯板（误区对比）**：演示“只吸高频不吸低频”导致高频发闷但低频依旧轰头的经典踩坑场景。
   - **QRD 二次余数实木扩散板**：打散镜面强反射脉冲，消除梳状滤波同时保留自然空间活度。
   - **高密度复合隔音阻尼板**：演示“隔音 ≠ 吸音”（提升对外隔声量 STC，但硬质表面不降低室内混响）。

3. **多维物理声学实时图表**
   - **6 倍频程 `RT60` 混响曲线**（Eyring-Norris 方程 + 空气高频吸收修正）。
   - **听音位低频驻波与边界干涉频响曲线（30Hz ~ 500Hz）**（简正模态格林函数叠加 + 一阶 SBIR 梳状滤波）。
   - **早期反射脉冲能量时间曲线 `ETC`** + **3D 地面低频驻波声压热力图**。

4. **实时可听化收音模拟（Web Audio Auralization）**
   - 实时合成双耳立体声房间脉冲响应（Synthetic Stereo RIR），一键无缝对比 **【干声原音】 vs 【空房混响】 vs 【当前方案收音】**，支持内置鼓组/低音贝斯/人声共振峰及上传本地试音曲。

5. **C++17 对照学习引擎（`cpp_core/`）**
   - [acoustic_engine.hpp](./cpp_core/acoustic_engine.hpp) 与 [acoustic_engine.cpp](./cpp_core/acoustic_engine.cpp) 提供了与前端 TypeScript 引擎 1:1 对应的现代 C++17 核心实现，附有面向 Java/Python 背景开发者的音频 DSP 内存与性能优化注释。

## 本地运行方式

```powershell
# 启动 Web 开发服务器
npm install
npm run dev
```

安装 C++ 编译器（如 MinGW-w64 `g++` 或 Visual Studio MSVC）后可独立编译运行 C++ 引擎测试：

```powershell
g++ -std=c++17 -O3 cpp_core/acoustic_engine.cpp cpp_core/demo_cli.cpp -o acoustic_sim.exe
./acoustic_sim.exe
```
